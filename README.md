# Resonance

安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:8015。

## 运动路径场景（Ink trajectory）

按 `5` 或点击场景列表中的 **Ink trajectory** 进入可编辑粒子路径。

- **绘制路线**：在预览画面中拖动圆形把手；双击把手删除、双击线段插入。
  方向键微调当前把手（`Shift` 加速），`Delete` 删除。路线可闭合或保持开放。
- **辅助线**：`G` 或右侧面板切换。辅助线绘制在独立的覆盖层上，舞台画布
  （以及 `canvas.captureStream()` 送进录制的画面）从不包含路径、把手或标签；
  录制期间与全屏观众视图下覆盖层也会自动清空。
- **末端处理**：开放路径可选「停留并淡出」或「回到起点」；闭合路径始终循环。
- **声音响应**：低频节拍触发整次发射（节拍用单调计数器累计，掉帧或低细节
  预览都不会吞掉短促节拍）；音量决定粒子沿法线扩散的宽度。
- **拖动时**：沿路径的位移始终精确，只有「路线本身移动」的部分会作为残差
  平滑收敛，所以已经飞出的粒子会流向新路线而不是瞬移。
- **尺寸含义**：路径与粒子都存于 0–1 舞台坐标，舞台位图固定 1280×720 由 CSS
  缩放，因此窗口大小与导出尺寸下同一时刻的形状和密度一致。
- **细节降级**：粒子超过约 380 个时预览会抽样绘制，但模拟与发射保持全量；
  录制期间不降级。
